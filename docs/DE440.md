# JPL DE440

The first simulation uses one planetary ephemeris for Sun, Earth and Moon. The reader returns geometric position in kilometres and analytic velocity in kilometres per TDB second. The frame is the DE440 ICRF3 basis. Positions use the solar-system barycenter as origin. The Earth is derived from the Earth–Moon barycenter and lunar series using the DE440 mass ratio.

Provide the [JPL little-endian classic DE440 file](https://ssd.jpl.nasa.gov/ftp/eph/planets/Linux/de440/linux_p1550p2650.440) with SHA-256 `29915576d0a6555766b99485ac3056ee415e86df4fce282611c31afb329ad062`. The previously prepared subset `de440-1900-2100.bin` also works with SHA-256 `d4c198e8ba6ca9dc75631ac22d742bb4f4d95d4c7ca87c7961b40b9800d36c67`. It retains records 3994 through 6277 and adjusts the coverage header. The binary is external to this repository. The loader verifies its byte length and SHA-256 and rejects epochs outside its inclusive coverage.

Set `SPACETANGENT_DE440` to the file's absolute path before running the core tests to enable the real-data checks. The committed reference vectors use CSPICE N0067 and the [official DE440s SPK](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp). They cover six epochs including both subset endpoints and a 32-day record boundary. The two formats use the same ephemeris through independent evaluation paths. The reference fixture can be regenerated with `tools/reference/generate_de440_reference.py`.

Source citation: Ryan S. Park, William M. Folkner, James G. Williams and Dale H. Boggs, *The JPL Planetary and Lunar Ephemerides DE440 and DE441*, The Astronomical Journal 161 (2021), 105. [DOI](https://doi.org/10.3847/1538-3881/abd414).

## Historical coverage

`HistoricalSolarEphemeris.Load` accepts either pinned DE440 file and the external `vsop87-legacy.bin` with SHA-256 `1865ca168437c9574c138af45c169902007c3ec463f4564f1e678b33e43c1217`. It extends the range to years 1–4000. The analytic path uses truncated VSOP87 for the Sun and eight planets, a 125-term geocentric lunar theory and a reference ellipse for the Pluto–Charon barycenter. Within DE440 coverage it returns the exact same kernel sample. Outside either endpoint, a 32-day Hermite correction matches position and velocity before fading into the analytic model. `SourceAt` identifies the active path. The historical model has a wider range and lower accuracy than DE440.

Set `SPACETANGENT_VSOP87` alongside `SPACETANGENT_DE440` for the historical tests. The legacy comparison fixture captures Sun, Mercury, Venus, Earth and Moon from a previous application build at three epochs. It converts that build’s native ecliptic coordinates to ICRF before comparison. The fixture checks compatibility with the archived model. The DE440 CSPICE reference continues to check the precise kernel separately.
The truncated planetary coefficients and lunar harmonics derive from GPL-2.0-or-later sources at revision `52075495b6194e23038cdabc7e126c80c5426dfb`. The VSOP87 implementation is by Chris Laurel (2002), using the series by Pierre Bretagnon and Gérard Francou. [Planetary series source](https://github.com/CelestiaProject/Celestia/blob/52075495b6194e23038cdabc7e126c80c5426dfb/src/celephem/vsop87.cpp) · [Lunar theory source](https://github.com/CelestiaProject/Celestia/blob/52075495b6194e23038cdabc7e126c80c5426dfb/src/celephem/customorbit.cpp)

## Analytical satellite orbits

`AnalyticSatelliteOrbit` evaluates eighteen parent-relative orbits using E5, TASS 1.7, GUST86 and the analytical Triton theory. The output is in the same axes as the planetary ephemeris. The Jupiter and Uranus series retain the mean-equator convention of the pinned catalogue. The velocity differentiates the position by sampling 30 TDB seconds on either side. The fixture contains 738 reference positions from the original implementation at 41 epochs. The comparison checks numerical compatibility with that implementation.
The truncated TASS 1.7 terms follow the GPL source at the same pinned revision. [TASS 1.7 source](https://github.com/CelestiaProject/Celestia/blob/52075495b6194e23038cdabc7e126c80c5426dfb/src/celephem/tass17.cpp)
