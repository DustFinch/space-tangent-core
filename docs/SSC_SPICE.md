# SSC spacecraft trajectories

The SSC reader loads spacecraft definitions with `SpiceOrbit`, local kernel paths, a mesh and a radius. It resolves the name or numeric ID of the SPK target and centre. The DAF reader accepts IEEE little- and big-endian kernels. The SPK evaluator supports geometric J2000 states with type 1 modified difference arrays and types 2 and 3 Chebyshev coefficients. Type 2 differentiates position to obtain velocity. Type 3 reads the separate velocity polynomials. Each direct trajectory reports its own coverage. Later matching kernels and segments have priority.

The Cassini regression uses the original `cassini.ssc` fixture and the NASA Cassini kernel `040615AP_SK_04167_04186.bsp`. Set `SPACETANGENT_CASSINI_SSC_ROOT` to the directory with the SSC, mesh and companion kernels. The expected positions and velocities come from CSPICE N0067 at five epochs, including both coverage endpoints. They can be regenerated with `tools/reference/generate_cassini_reference.py`.

The reader evaluates `SpiceRotation` for J2000 CK type 3 frames. It reads the frame ID and clock link from FK, converts TDB to encoded clock ticks using SCLK type 1, and interpolates only inside CK pointing intervals. The second regression compares five attitudes and one pointing gap with CSPICE using the original Cassini kernels. It can be reproduced with `tools/reference/generate_cassini_attitude.py`.

The conic, sampled and SPICE readers accept an ordered list of SSC paths. `Modify` changes the supplied properties and keeps omitted properties. Orbit and rotation blocks are replaced as units when a different model is supplied. `Replace` takes the new definition while preserving an existing body's primary name and aliases. Both directives create a definition if the name is new. Duplicate additions are rejected as ambiguous. Resource paths stay relative to the catalogue that supplied the effective property. A `SpiceRotation` block can supply its own ordered kernel list. The overlay regression uses the original Cassini trajectory, pointing and model with a locally authored patch in a separate directory.

The version 1.0 SPICE JSON adapter shares the same trajectory and attitude readers. It expands ordered local metakernels, including relative path symbols, within the supplied add-on root. The original Cassini SOI JSON regression is enabled by setting `SPACETANGENT_CASSINI_JSON_ROOT` to its directory. It loads the spacecraft and both cameras. The sensor reader resolves IK instrument aliases, rectangular fields of view and Euler FK rotations directly into the spacecraft CK frame. It preserves the target, range, color and opacities. The regression compares both boresights and all eight corners at two epochs against CSPICE N0067. Run tools/reference/generate_cassini_fov.py with the CSPICE library, the original add-on directory and a leap-seconds kernel to regenerate the reference.

The SAT480 regression uses Saturn's physical center (699) relative to the system barycenter (6). Set `SPACETANGENT_SAT480` to the original kernel, SHA-256 `12D2CFD8DA371883BD4EDBD67C31FAFA98CA7779A09DA6819E29D53CDC6DAF32`. The reference covers Cassini mission epochs, both coverage ends, and record and segment transitions. Regenerate it with `tools/reference/generate_saturn_center.py`.

[NAIF SPK format and interpolation types](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/spk.html) · [SAT480 data and provenance](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/satellites/sat480.cmt)

For geometric camera intercepts, Saturn's physical center comes from SAT480 and its orientation and radii come from the standard IAU polynomial model in `pck00011.tpc`. Set `SPACETANGENT_SATURN_PCK` to that original file, SHA-256 `3DFF7B1DBECEAA01F25467767D3FA25816051C85D162D1EDF04ACB310EE28BB1`. The ray and target share one TDB epoch. The closest forward intercept must lie within the catalogue range. The independent fixture includes both cameras' boresights and corners with hits and misses.

The sampled SSC adapter selects a named spacecraft from a multi-object catalogue. It evaluates cubic double-precision XYZV phases in their declared J2000 ecliptic frames, with the centers and two-vector attitude resolved through the same world graph. Calendar phase times are TDB. The beginning is inclusive and the ending is exclusive, so an exact join selects the next phase.

Set `SPACETANGENT_SSC_WORLD_ROOT` to the original world data root to check all 15 Cassini phases in `ssc/cassini.ssc`. The 45 reference states combine an independent Hermite calculation from the original XYZV files with the CSPICE J2000 rotation and DE440 center states.

The same catalogue supplies the three Huygens trajectory phases. The mount uses the Cassini body frame, free flight uses `huygens.xyzv` relative to Titan, and the landed phase follows Titan's rotating PCK frame. The source `Planetographic` tuple follows the SSC fixed-position convention, a planetocentric direction with altitude above a sphere of radius 2575.15 km from the PCK. The world graph also applies the catalogue's fixed mount angles, spin relative to the Saturn-centered direction frame, and landed attitude relative to Titan. Register Titan (606) with its PCK frame and the physical Saturn center (699), both from `sat083.bsp`. The regression checks relative position, velocity and attitude in each phase, both boundaries, carrier coverage before Titan ephemeris coverage begins, and the separate transformation from SSC mesh coordinates to body coordinates.

The world graph can register a body from a local SPK with an IAU polynomial PCK frame. It evaluates orientation and analytic angular velocity from the same TDB epoch, including the transport velocity of a point fixed to that body. The regression uses Titan from `sat083.bsp` and Saturn from `sat164.bsp` to exercise both Chebyshev representations. Set `SPACETANGENT_SAT083`, `SPACETANGENT_SAT164` and `SPACETANGENT_SATURN_PCK` to the original files. The fixture compares centers, orientation and orientation derivatives with CSPICE at Huygens mission epochs and coverage endpoints.
